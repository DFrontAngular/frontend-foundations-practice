# 05 — DOM seguro y delegación

Renderiza una lista de comentarios que procede de datos externos. Crea cada nodo con APIs del DOM y usa un solo listener en la lista para marcar favoritos.

- No uses `innerHTML` con contenido de comentarios.
- Los botones generados deben funcionar sin listeners individuales.
- El estado es un array de datos y renderizar no debe mutarlo.
