# Itinerario

1. HTML: semantica, estructura, formularios, tablas y accesibilidad.
2. CSS: cascada, composicion, responsive y estados.
3. JavaScript logico: funciones, colecciones, modulos y errores.
4. DOM y HTTP: eventos, formularios, URL, storage y asincronia.
5. TypeScript: contratos y fronteras entre datos confiables y externos.
6. Capstone: gestor de colecciones sin framework.

El curso contiene 32 ejercicios guiados y un capstone. La progresion esta pensada para que las abstracciones de React, Angular u otro framework sean comprensibles, no magicas.
