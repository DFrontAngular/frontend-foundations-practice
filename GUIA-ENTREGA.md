# Guia de entrega y revision

Cada persona trabaja desde un fork. `main` conserva el material limpio; cada ejercicio se desarrolla en una rama propia y se integra mediante Pull Request en la rama `solutions`. Consulta [FLUJO-GIT.md](FLUJO-GIT.md) antes de empezar.

Cada Pull Request debe incluir commits comprensibles y:

1. Que implemento y que criterios cumple.
2. Que decisiones tecnicas tomo y por que.
3. Como lo comprobo: tests, DevTools, teclado, red o casos limite.
4. Que ayuda externa o IA utilizo.
5. Que parte resulto dificil y que mejoraria.

La IA puede explicar conceptos, proponer casos de prueba o revisar una primera solucion. No sustituye la capacidad de explicar, modificar y depurar cada linea relevante.
