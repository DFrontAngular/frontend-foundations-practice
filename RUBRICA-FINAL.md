# Rubrica de salida

Una persona esta preparada para pasar a un framework cuando alcanza como minimo nivel 2 en cada area esencial.

| Area                 | Nivel 2: funcional                                                 | Evidencia                     |
| -------------------- | ------------------------------------------------------------------ | ----------------------------- |
| HTML y accesibilidad | Estructura semantica y teclado correctos                           | Ejercicios 01-HTML y capstone |
| CSS                  | Layout responsive sin reglas fragiles                              | Bloque CSS y capstone         |
| JavaScript           | Funciones claras, datos sin mutacion accidental y errores tratados | Bloque 03                     |
| DOM                  | Estado derivado y renderizado seguro                               | Bloque 04                     |
| HTTP                 | Loading, error, vacio y exito coherentes                           | Bloque 04 y capstone          |
| TypeScript           | unknown, unions y contratos sin any                                | Bloque 05                     |
| Autonomia            | Depura y modifica un requisito nuevo                               | Defensa del capstone          |

La media no compensa una carencia esencial. La persona debe explicar el flujo desde una interaccion hasta la actualizacion de datos y de interfaz.
